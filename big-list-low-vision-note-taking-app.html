Big List Features

Designed for Low Vision Users

This List-Making To-Do App has huge line height and extra spacing between lines for easier reading and interaction.

High Contrast and Clear Print

Big List offers large, clear print for maximum visual clarity at all times.

Easy List Management

To delete a list item, swipe it to the left. The large line height makes this process accurate and accessible.

Reorder Lists with Ease

Tap the edit button to enable reordering. Use the red diamonds to drag items up or down in the list.

Built-In Large Print Emailer

Use the built-in email function to send any list item. Type and review content in large print before sending.
